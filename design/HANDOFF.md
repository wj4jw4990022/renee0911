## 二、主畫面（定案）

- 對話和看勇者走動一樣重要；**對話區維持原本高度**
- 勇者卡縮小（頭像 34px），鈴鐺、跟拍變小
- 對話字 14px、行距放鬆
- 問題**直接出現**；三個選項排一排、只有金色外框（按下才變色）；「已讀不回」改右下小字
- 名牌**全部保留**：建築＝小木牌，人名＝白字細黑邊、不加底框
- 上方金庫用像素金幣、名聲用像素星星
- 顏色規則：金色只給「現在要按的那一個」，綠＝好事，紅＝警告，其他用中性色
- 字：點陣字（Cubic 11）只用在標題、數字、按鈕，大小只用 12／16／24px；內文用一般字體
- 草圖：`sketches/sketch_v30.png`、`sketches/mock_cmp2.png`；樣式：`drafts/layout-and-spend-page.css`

## 七、tools/ 說明

| 檔案 | 用途 |
| --- | --- |
| `pixel.py` | 高解析插圖 → 小尺寸像素圖（縮小、去半透明、減色、加深棕外框） |

| `emote.py` | 表情泡泡外框＋第一版 18 個圖示 |

| `emote_final.py` | 輸出目前定案的表情總表：`python3 emote_final.py 輸出資料夾` |
| `chibi.py` | 44×60 的手工程序角色（示範用，最後方向是用 Kenney） |
| `sketch2.py`、`mock.py`、`theme.py` | 產生草圖截圖用（無頭瀏覽器） |
