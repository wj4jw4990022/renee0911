# 勇者經紀人｜定案圖檔（2026-11-26）

## emotes/ 表情泡泡（18 個）

- 每個表情都有 `名稱.png`：原尺寸（1 格＝1 像素），白底泡泡、深色外框、透明背景。
- 有動畫的 10 個另外有：
  - `名稱_frames.png`：所有影格橫排成一張，每格寬高見 json
  - `名稱.json`：`frame_w`、`frame_h`、`frames`（張數）、`durations_ms`（每張顯示幾毫秒，播完從頭循環）
  - `名稱.gif`：放大 8 倍的預覽，給人看用，遊戲裡請用 frames.png
- 影格一律靠下對齊，泡泡尾巴位置不會跳動。

## equipment/ 裝備圖示（32×32，16×16 放大 2 倍）

- `sword0～3` 劍（戰士）、`bow0～3` 弓（弓手）、`staff0～3` 杖（法師，斜桿＋正圓水晶球）、`dagger0～3` 匕首（盜賊，微彎小刀、沒有護手）
- 0～3＝木、鐵、鋼、秘銀；杖的寶石依序是綠、紅、藍、紫
- `armor0～3`：布衣、皮甲（皮背心套在布衣外）、鎖子甲、板甲（全身甲含護臂）
